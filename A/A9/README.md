# A9 — The Body of Software

*A Model Can Be Replaced. The Interface That Lets It Act Should Not Disappear With It.*

**Zawwar Sami** · Artificial Agency / A9 · **Independent preprint v1.9** · 14 October 2026 · 10 pages

A model can plan or request an action without possessing a dependable means of acting in its environment. This paper examines the persistent device-facing interface that gives a replaceable AI controller somewhere to observe and act. Drawing on source-attributed excerpts from the Loki Android application, I propose a **Causal Embodiment Contract**: a way to investigate what survives a model substitution, what changes with the controller, and how both actions and permissions can be checked.

The paper's most specific proposal is the **model-swap coverage gap**. A more capable replacement model may exercise new, authorized routes—or reveal that a restricted source was never governed consistently across equivalent routes. This is an engineering research proposal with counterfactual examples and proposed tests, **not** a controlled Android experiment or a demonstrated live security leak.

## A question to test

Two controllers operate the same Android interface under the same owner-granted permissions. The replacement model discovers a source via a different observation route that the original controller never exercised. **What evidence would distinguish new competence within unchanged authority from a missing permission check?** Which comparisons would falsify the proposed value of treating the persistent interface as an independently tested 'body'?
